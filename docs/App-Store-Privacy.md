# OctoRole 商店版私隱政策

OctoRole 由 Octopus InfoTech Limited 開發。項目、劇本、參考相、角色對白同輸出影片儲存喺你部 Mac。生成預演時，App 會將描述交畀你設定嘅本機 Qwen 服務。生成影片同配音時，H3 同 Qwen3-TTS 會喺 Mac 上處理素材。

下載 H3 模型時，App 會透過互聯網連接 Hugging Face。供應商會收到完成下載所需嘅網絡資料，包括 IP 位址同檔案請求。你可以喺 Hugging Face 網站查閱供應商嘅私隱政策。首次下載完成後，可以重用已儲存嘅模型。

你可以喺作品頁刪除輸出檔案，或者喺 Finder 管理自己已匯出嘅副本。你自行分享嘅影片同相片會交畀你選擇嘅收件人或平台。

如有私隱查詢，可以透過公司嘅 [OctoRole 支援頁](https://github.com/Octopus-InfoTech-Limited/OctoRole/issues) 聯絡開發團隊。公開留言請勿附上私人素材或聯絡資料。
